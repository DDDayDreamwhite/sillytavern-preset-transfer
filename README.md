# 预设迁移助手 0.3.0

这是用于 SillyTavern 的浏览器扩展，支持含 prompts / prompt_order 的聊天补全预设。
打开酒馆的扩展设置，展开“预设迁移助手”。选择旧自用版、新原版，可额外选择旧原版，然后点“分析文件”。
有旧原版时，工具比较三份文件，把用户改动和作者更新对照起来。只有两份文件时，正文有差异的对应项需要选择保留哪一边。

从 A 勾选缝入 B
在顶部选择“从 A 勾选条目缝入 B”，选择来源 A 与目标 B，点分析。勾选要缝入的条目或正则，再处理这些已勾选项的对应关系。默认所有项均未勾选。
初始位置参考来源 A 中前面的对应条目，找不到时再参考后面的对应条目。两边都找不到时追加到末尾。只有已勾选内容参与迁移和开关恢复。
需要配套的正则或脚本时，请分别勾选对应项。工具不会从自然语言规则自动推断这些依赖。

调整最终顺序
处理完已勾选的冲突后，点“预览并调整最终顺序”。选择条目排序配置或正则执行顺序，按住每行左侧六点手柄拖动，目标位置会显示插入线。拖到列表边缘可自动滚动，Esc 取消。也可使用上移、下移按钮。
导出的 JSON 使用调整后的顺序。修改勾选、处理方式或输入文件会清除这次排序草稿，需重新生成预览。不同条目排序配置分别调整。

外观
界面使用半透明毛玻璃。右上按钮切换白天、夜间模式，并在当前浏览器记住选择；首次使用跟随系统明暗偏好。
实际透出的背景取决于酒馆主题及扩展设置面板的背景。界面预览图使用模拟宿主背景。

迁移预览
• 条目按标识、唯一名称、同名项中的相同正文匹配。带版本号的相似名称会提示可能对应项。
• 重名或双边修改会标成“待选择”。展开条目可看完整原文，并手动选择新版对应项。
• “接入已识别的自用修改”逐字段搬入只有用户改过的字段，保留作者对其他字段的更新。
• “使用旧自用内容”会用旧条目的完整字段替换该新版条目，包括注入配置。
• “作为独立条目加入”适用于自加条目。标识冲突时会生成新标识。
• 默认恢复各排序配置中的条目开关及正则开关，并将新增条目放到旧版相邻项之后。
• 新版原有条目的相对顺序保留。排序大幅改动、规则语义冲突和宏变量是否齐全仍需阅读预览判断。
• 正则与助手脚本作为数据搬运。助手脚本、其他扩展数据和生成参数出现冲突时也会列出选择。
• 文件内容只在浏览器内处理。导出 JSON 后，通过酒馆原有的预设导入功能导入，再检查实际生成与正则显示。

安装
在酒馆的扩展管理中选择“安装扩展”，粘贴以下仓库地址：

https://github.com/DDDayDreamwhite/sillytavern-preset-transfer

刷新酒馆，在扩展管理中启用“预设迁移助手”，到扩展设置里使用。
ZIP 是安装包。酒馆“安装扩展”输入框通常需要 Git 仓库地址，本包尚未发布到仓库。
如需撤回，在扩展管理中禁用该扩展并刷新页面。
